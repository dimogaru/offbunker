---
name: Afirmaciones públicas de privacidad y planes
description: Criterio para el contenido comercial de OffBunker frente a funciones aún no implementadas.
---

La página pública debe separar las capacidades actuales de propuestas futuras: el almacenamiento personal móvil es local, pero la aplicación no cifra esos archivos por sí misma. Los límites gratuitos sí están activos; PRO, suscripciones y pases siguen siendo propuestas no contratables. Pulse se ofrece como vista previa, no como una ventaja PRO ya adquirible.

**Why:** El usuario eligió activar los límites gratuitos antes de habilitar la contratación de PRO. Presentar un desbloqueo inmediato o capacidades de pago como operativas induciría a error; el borrador anterior también exageraba el cifrado local.

**How to apply:** Al actualizar seguridad o precios, distinguir los límites vigentes de las ventajas futuras. Mantener «Próximamente» y no ofrecer compra ni prometer un desbloqueo disponible hasta verificar que existe contratación y autorización reales.
