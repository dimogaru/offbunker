---
name: Afirmaciones públicas de privacidad y planes
description: Criterio para el contenido comercial de OffBunker frente a funciones aún no implementadas.
---

La página pública debe separar las capacidades actuales de propuestas futuras: el almacenamiento personal móvil es local, pero la aplicación no cifra esos archivos por sí misma. Los límites gratuitos están activos; PRO Beta se regala a cuentas registradas y desbloquea viajes y gastos ilimitados, pero no hay contratación de pago. Pulse y la comprobación offline siguen en vista previa para todos; más almacenamiento aún no existe.

**Why:** El usuario pidió un desbloqueo gratuito de PRO Beta al alcanzar cuotas, pero no pidió activar compras ni implementar más almacenamiento. Presentar las otras ventajas propuestas como exclusivas o ya concedidas induciría a error; el borrador anterior también exageraba el cifrado local.

**How to apply:** Al actualizar seguridad o precios, distinguir las cuotas vigentes y la concesión gratuita de las ventajas futuras. No prometer compras, capacidad extra de nube ni funciones exclusivas que aún no existen; no volver a describir PRO Beta como indisponible.
